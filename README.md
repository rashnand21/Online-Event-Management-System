# Online Event Management System

A web-based Online Event Management System developed using Python Flask and MySQL.

## Project Overview
This project helps users explore and book events through a web application. It also provides management features for organizers and administrators.

## Technologies Used
- Python
- Flask
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Project Structure
- `app.py` – Main Flask application
- `db.py` – Database connection
- `templates/` – HTML templates
- `static/` – CSS and JavaScript files
- `Event.sql` – Database SQL file
- `requirements.txt` – Python dependencies

## Installation and Setup

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Create a MySQL database and import `Event.sql`.
4. Create a local `.env` file with your own database credentials.
5. Run the application:

   `python app.py`

6. Open `http://127.0.0.1:5000` in your browser.
